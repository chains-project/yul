# tasker

A small command-line task manager built with [Click](https://click.palletsprojects.com/).

## Install

```sh
pip install -e .
```

## Usage

```sh
tasker add "write the report" --priority high
tasker list
tasker done 1
tasker remove 1
```

Run `tasker --help` or `tasker <command> --help` for full option details.
